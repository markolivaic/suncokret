what this cannot tell you

No model is trained and none runs. This is shadow geometry and irradiance bookkeeping. There is no ground truth: nobody publishes per-roof generation for Zagreb, so nothing here has been checked against a real installation. Comparing two roofs is meaningful because both sides come from the same pipeline. An absolute figure in kWh is not, and this page does not show one.
